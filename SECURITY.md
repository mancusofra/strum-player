# Security

Strum Player runs entirely on the device and has no servers or accounts: the most likely
vulnerabilities involve opening song files.

## Reporting a vulnerability

**Do not open a public issue.** Use GitHub's private reporting:
[Security → Report a vulnerability](https://github.com/mancusofra/strum-player/security/advisories/new).

Include the version, the platform and the steps to reproduce the problem. You will get an answer
as soon as possible; once the issue is fixed the report will be published, crediting you if you
wish.

## Supported versions

Only the latest version receives fixes.
